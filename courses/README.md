# 从这里开始上课

**现在只打开 [第 01 课：两个服务，谁真的更快？](01/README.md)，或对助手说“带我学第 01 课”。** 不用自己找阅读顺序，不用准备 GPU。

每次 30–45 分钟：我先讲一个服务问题 → 你做一个预测 → 一起操作实验 → 补必要原理 → 看一小段真实源码 → 你解释结果。可以拆成多次，不按周追债。

| 课 | 你将解决的问题 | CPU 实验 |
|---|---|---|
| [01](01/README.md) | QPS 高，为什么用户仍觉得慢？ | 请求时间线与分位指标 |
| [02](02/README.md) | 带宽已满，还能提高吞吐吗？ | 权重复用与 roofline 上界 |
| [03](03/README.md) | 权重放得下，为什么 OOM？ | KV/GQA/分页取整 |
| [04](04/README.md) | 长请求为何干扰短请求？ | token 预算教学调度 |
| [05](05/README.md) | 相似 prompt 为何不命中？ | 完整前缀 block 与容量 |
| [06](06/README.md) | INT4 更小，为何未必更快？ | outlier/scale/误差与成本 |

```bash
python3 scripts/lab.py lesson --id 01
python3 scripts/lab.py lesson --id 01 --params
```

每课的 `--params` 给出参数说明、允许值和默认值；`--set NAME=VALUE` 可以重复，但学习时一次只变一个条件。默认只输出结果，不改写笔记。不会安装 PyTorch、vLLM 或加载模型。

## 你需要做什么

负责预测、说出疑惑、观察并解释；环境准备、源码定位和图表操作可由助手带着做。先看学习页，教师页是分步提示与答案，不必提前翻。不会只提问而不讲解，也不会把你还没理解的内容标成完成。

## 教材与证据

MLSysBook 按具体小节选读；课程是原创讲解与简化模型，不复制整章。外部教材随时间变化，核对日期 2026-09-07。源码固定在 vLLM v0.19.0，完整 commit/symbol/文件 hash 见 [source-lock.json](source-lock.json)。这是教学基准，不代表当前最新版本或生产配置。

所有模拟只验证机制，理论估计只给上界/下界。每课另有远程验证设计，只有完成指定硬件实测、质量与完整样本检查后才能讨论生产收益。
