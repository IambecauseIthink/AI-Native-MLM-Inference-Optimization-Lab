# Topic

精确主题、scope、status、日期、来源 revision。

## One Sentence Summary

用一句因果句解释，不写宣传语。

## Problem

业务或系统瓶颈是什么？

## First Principles

从算力、字节、依赖、队列推导问题。

## Naive Solution

最简单办法是什么？为何不够好？

## Core Idea

减少了什么工作，增加了什么成本？

## System Position

Model / Runtime / Scheduler / Memory / Kernel / Serving；画上下游。

## Implementation

数据结构、算法、复杂度、输入输出与真实实现。

## vLLM

repository + commit + file + symbol；入口与实际执行分支。

## Experiment

假设、预测、控制、变量、baseline、反例、停止条件。

## Metrics

质量、QPS/GPU、输入/输出/总 TPS、TTFT、TPOT、E2E、显存。

## Results

未运行写 not-measured；附完整 run/原始证据，不填估造数字。

## Why

为什么如此？还有什么解释？下一步如何区分？

## Limitations

何时无效？硬件、shape、质量与维护限制。

## Production Value

相对当前生产 vLLM baseline 的增益、SLO 与成本。

## Interview Questions

原理题、系统设计题、证伪题各一。

## My Thinking

先由我独立判断，再记录 AI 反驳与证据裁决。
