# AI research task

## Question and human prediction

研究者填写问题、因果预测、业务约束与预期反例。

## Context

关联笔记、精确 repo/revision、输入/数据权限、当前证据、允许操作。

## Bounded task

Theory / source navigation / prototype / benchmark / review 中选一个；列交付物、允许改动、禁止改变的实验条件。

## Acceptance

正确性 oracle、误差容差、失败测试、benchmark 合同、证据格式、退出条件。无证据的结果必须为 unknown。

## Review

输出修改、为什么、如何验证、证据与局限；提供最强竞争解释。研究者负责判断结论。
